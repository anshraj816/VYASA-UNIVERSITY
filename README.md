# VYASA UNIVERSITY

A complete responsive multi-page university website created using HTML, CSS, and JavaScript.

## 🎓 Website Overview
- **Home**: Welcome banner, courses overview, campus tours, facility highlights, testimonials, call to action.
- **About Us**: University history, mission, vision, and campus facilities.
- **Courses**: Undergraduate, postgraduate, and diploma program listings.
- **Blog**: Campus news, student achievements, and academic updates.
- **Contact Us**: Interactive map, inquiry form, and university contact details.

## 🚀 Technologies Used
- HTML5
- CSS3 (Flexbox, Grid, Media Queries)
- JavaScript
- Font Awesome & Google Fonts
